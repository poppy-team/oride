# User Experience Research (UXR) Quality Checklist

## 1. Study Planning & Participant Recruitment
- [ ] **Falsifiable Hypotheses**: Research plan identifies specific assumptions and measurable risk questions.
- [ ] **Target Screening**: Participant criteria represent actual target user personas; internal team members excluded.
- [ ] **Sample Size**: 5 to 8 participants per primary user segment to achieve statistical thematic saturation.
- [ ] **Ethics & Consent**: Informed consent obtained; recording permissions and data privacy policies enforced.

## 2. Task Design & Facilitation Neutrality
- [ ] **Non-Leading Prompts**: Tasks describe end goals rather than the interface path or button labels.
- [ ] **Clear Success Criteria**: Explicit definition of when a task is considered completed vs failed.
- [ ] **Think-Aloud Protocol**: Facilitator encourages concurrent verbalization without coaching or correcting the participant.
- [ ] **Zero Interface Defense**: Facilitator does not defend designs or explain system features during testing.

## 3. Quantitative Measurement & Metrics
- [ ] **Task Completion Rate (TCR)**: Binary success/failure tracked for every participant and task (target: $\ge 80\%$).
- [ ] **Single Ease Question (SEQ)**: Administered post-task using standard 1-7 scale (target: $\ge 5.5$).
- [ ] **System Usability Scale (SUS)**: Administered post-test using all 10 standard questions and proper mathematical scoring.
- [ ] **Time on Task (ToT)**: Duration from task prompt to completion/abandonment recorded.

## 4. Synthesis & Recommendations
- [ ] **Evidence-Backed Insights**: Findings cite specific observed behaviors or quotes rather than evaluator opinion.
- [ ] **Severity Prioritization**: Issues categorized by frequency of occurrence and severity of business/task impact.
- [ ] **Actionable Takeaways**: Recommendations specify concrete UX or technical improvements.
