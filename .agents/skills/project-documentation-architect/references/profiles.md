# Profiles -> mandatory contract packs (minimum)

Detect all that apply: Core, CLI, TUI, Desktop GUI, Web, Mobile,
API/Service, Data, Library/Package, Plugin Host/SDK, Compiler, Language,
Game, Engine, Graphics/Rendering, 3D/Creative, Distributed, Dev Tool,
Automation, Agent/Harness, AI-enabled, Research, Learning, Embedded,
Kernel/Driver.

- CLI: command/flag/exit-code contract, error model, golden stdout tests.
- GUI/TUI/Web/Mobile: IA map, screen inventory, semantic wireframes, layout
  spec, component contracts plus states, semantic tokens, keyboard map,
  independent a11y review, visual verification with real screenshots.
- API/Service: versioned contracts, compat policy, auth, errors, ops runbook.
- Library/Package: public surface, semver, minimal example, migration notes.
- Compiler/Language: grammar/spec, diagnostics catalog, conformance tests.
- Plugin/SDK/Agent: extension points, capability boundaries, sandbox model.
- Data/Distributed: consistency, failure modes, recovery, migration.
- AI-enabled: model boundary, evals, data/privacy, offline fallback.
