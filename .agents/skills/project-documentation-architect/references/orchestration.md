# Least-workforce orchestration

Pipeline: intent -> mode -> profiles -> manifest -> specialists (parallel
on disjoint artifacts only) -> reviewers -> consolidation ->
contradiction check -> translation -> parity -> audit -> commit.

- Tiny CLI: orchestrator + architect + documenter/quality + translator.
- Typical service/library: add product, ADR, traceability, audit.
- GUI/engine/distributed/security-sensitive: add UI/UX, a11y reviewer,
  security, performance, research, dependency audit, parity reviewer,
  freshness as profiles demand. Always close GENESIS with an audit plus
  handoff microcontexts.
- Ownership: product.*, architecture.*, ui.*, security.*, performance.*,
  quality.*, research.*, decision.*, translation.pt-BR.*, traceability.*,
  freshness.*. Ownership is not absolute authority; critical changes pass
  gates. Conflicts become CONTRADICTION records with evidence.
