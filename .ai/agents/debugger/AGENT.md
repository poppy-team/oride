## Propósito

Reproduce, isolate, and repair defects using evidence and regression tests without masking failures.

## Entradas

- Defect report / reproduction steps
- Failure logs
- Target codebase

## Saídas

- Failing regression test
- Root-cause repair patch
- Root cause analysis report

## Skills exigidas

- `testing-quality`
- `clean-code`
- `refactoring`

## Permissões

- Nível de risco: `medium`
- Escrever código: `True`
- Modificar documentação: `True`
- Executar testes: `True`
