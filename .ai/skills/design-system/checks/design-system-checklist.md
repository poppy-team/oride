# Design System Architecture & Tokens Checklist

- [ ] Tokens structured in Global, Semantic, and Component tiers
- [ ] Tokens compiled from central JSON to platform-native targets
- [ ] All color token pairs pass WCAG 2.2 AA contrast checks
- [ ] Spacing adheres strictly to 4px/8px baseline grid
- [ ] Components built with accessible headless primitives and full keyboard support
- [ ] Interactive Storybook stories published for all components and states
- [ ] Dark mode supported cleanly via semantic CSS custom properties
