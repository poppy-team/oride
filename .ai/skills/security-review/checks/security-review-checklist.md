# Security-Focused Code Review Checklist

- [ ] Code changes evaluated against system threat model and trust boundaries
- [ ] SAST and security linters pass with zero blocking vulnerabilities
- [ ] Independent security reviewer assigned for High and Critical risk changes
- [ ] Automated test cases included to verify security fix efficacy
- [ ] Unregistered escape hatches, unsafe pointers, or suppressions rejected
- [ ] Defense-in-depth validated: multiple interlocking security layers present
- [ ] Review verdict and gate evidence recorded in project compliance history
